# WCPs VKD3D

Faça upload nesta pasta do arquivo `VKD3D-3.1.0-Gamesir-FIX.wcp` disponibilizado no chat.

Depois de enviar, execute `python3 scripts/update_contents.py` e faça commit do `contents.json` atualizado. O arquivo só aparecerá no catálogo depois disso.

Não faça upload do ZIP com DLLs como se fosse um WCP: Winlator exige TAR/XZ com `profile.json`.
