# ZIPs Turnip

Faça upload nesta pasta do driver Turnip GameHub convertido para o formato **Adrenotools ZIP** válido.

O pacote necessita `meta.json` e bibliotecas nativas compatíveis. A compatibilidade com GameHub não prova funcionamento no Winlator.

Não adicione o driver Turnip como tipo `VKD3D` no `contents.json`.
